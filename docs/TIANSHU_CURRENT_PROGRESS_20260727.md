# 天枢当前进度与改进进展

更新时间：2026-07-27
目标仓库：`liaoj0330-bot/tianshu-next-`
正式状态权威：SQLite

## 一句话结论

天枢的受控执行、连续性、项目治理和 AgentHub 接入底座已经成立；本轮重点从“能不能执行”转向“能不能自然对话、正确判断、长期恢复并安全进入复杂执行”。当前仍是私人开发与真实任务试运行阶段，不能描述为已经完成公开生产部署。

## 本轮已验证进展

### 1. 基础对话不再只返回固定模板

- 能力询问可以直接回答，不再一律反问目标。
- 简短追问会结合前文承接，不再重复通用澄清问题。
- 普通陈述可以自然回应，不会擅自创建任务。
- AgentHub 可以读取经过权限过滤的创建者与可见项目背景，受保护项目不会泄漏。

### 2. Agent 决策层已具备安全接入结构

- 保留原有规则判断作为可回退基线。
- 支持 `off`、`shadow`、`active` 三种模式。
- Shadow Mode 只记录模型判断与规则判断差异，不改变正式结果。
- Active Mode 只能覆盖语义路由，不能直接授予执行权。
- 模型输出必须通过结构化契约校验；任何直接执行尝试都会被拒绝。
- 决策审计以追加方式写入 SQLite，可通过只读接口查看。

### 3. Codex 执行适配层继续收敛

- 新增 Codex SDK 适配器候选。
- 工作目录与非交互沙箱边界由批准后的执行合同提供。
- SDK 与原 CLI 保留显式切换能力，避免单一执行入口失效后无法恢复。

### 4. 长期状态和治理边界保持有效

- SQLite 仍是唯一机器状态源。
- Executor、Verifier 和创建者的权限继续分离。
- 计划确认、执行边界确认和最终结果接受仍是不同决策。
- 超时、取消、有限重试、恢复、备份和项目锁继续由正式运行时管理。
- Markdown、界面和 Obsidian 只做说明与只读呈现，不能反向覆盖正式状态。

## AgentHub 开发版协同进展

以下能力已经在 AgentHub 开发工作区本地实现并验收，但尚未作为 TianShu Next 后端代码合并到本仓库：

- Graph Lite 任务图：`上下文 -> 确认 -> 调配 -> 执行 -> 验收`。
- 发布、上传、覆盖、删除、上线等高影响动作会在调用 Agent 前暂停。
- 用户确认后恢复原任务；取消后下游节点跳过。
- 任务图状态可以持久化，界面可查看节点状态。
- 共创推演协议：探索现状、重构问题、形成不同路径、比较选择、确认后交接执行。
- 普通聊天保持直接对话，不强制进入任务图或深度访谈。

这部分当前属于“AgentHub 交互与执行层已完成本地验证，TianShu Next 正式任务图合同待对齐”，不能写成两个仓库已经完全合并。

## 当前未完成

1. TianShu Next 本地仍有一批功能改动尚未形成独立提交，不能称为已经同步到 GitHub。
2. Agent 决策引擎缺少带真实 API Key 的 Shadow 对比和 Active 小流量验收。
3. TianShu Next 与 AgentHub Graph Lite 尚未统一任务图持久化合同；当前两边各自保存运行状态。
4. 公众号、视频号等平台仍缺少经过真实账号验收的发布连接器；现阶段不能宣称已经全自动发布。
5. 公开部署前仍需补齐身份认证、网络边界、备份恢复演练、监控告警和持续真实任务验证。
6. 高校课程、教师 AI PPT、自媒体与县域产业等业务成果必须继续由各自授权项目提供证据，本仓库不读取受保护业务仓库来制造完成度。

## 下一阶段优先级

### P0：把本地候选改动变成可审查提交

- 独立审查 Agent 决策层、聊天上下文、Codex SDK 适配和相关迁移。
- 保持功能提交、文档提交和运行数据分离。
- 每个提交都附对应测试与失败边界。

### P1：完成真实模型决策验收

- 配置受控 API Key。
- 先运行 Shadow Mode，比较真实模型与旧规则。
- 对错误样本做归因，不为了提高数字改写期望答案。
- 只有 Shadow 结果稳定后，才允许小范围 Active Mode。

### P2：统一 Graph Lite 合同

- TianShu Next 继续作为 SQLite 状态权威。
- AgentHub 负责对话、节点可视化和人工确认。
- 统一 `workflow_run`、`node_run`、依赖、重试、确认和验收字段。
- 不建立第三套 Markdown 任务状态。

### P3：从一个真实内容闭环开始

- 先打通“授权素材 -> 公众号内容包 -> 草稿箱 -> 人工确认发布 -> 数据回收”。
- 正式发布保留最终人工确认。
- 发布数据回写后，再决定是否扩展视频号和其他平台。
